📖 사용 가이드

                
            

            

                

                    
🎯 DiagramFlow란?

                    
DiagramFlow는 데이터베이스 ERD(Entity Relationship Diagram)를 쉽고 빠르게 만들 수 있는 협업 도구입니다.

                


                

                    
🚀 빠른 시작

                    
    
                        
  1. 테이블 추가: 왼쪽 사이드바의 "📊 + 테이블 추가" 버튼 클릭
    2. 
                        
  2. 테이블 편집: 추가된 테이블을 클릭하거나 우클릭하여 편집
    3. 
                        
  3. 컬럼 추가: 테이블 편집 화면에서 "컬럼 추가" 버튼 클릭
    4. 
                        
  4. PK 설정: 컬럼 행의 "🔑 PK" 체크박스 선택
    5. 
                        
  5. 관계 연결: 2개 이상의 테이블 생성 후 "🔗 + 관계 추가" 버튼 클릭
    6. 
                    

                


                

                    
🔑 주요 기능

                    

                        

                            
📊 테이블 관리

                            
테이블을 드래그하여 자유롭게 배치하고, 컬럼의 타입과 속성을 설정할 수 있습니다.

                        

                        

                            
🔗 관계 설정

                            
테이블 간의 1:1, 1:N, N:N 관계를 시각적으로 표현하고 외래키를 자동으로 생성합니다.

                        

                        

                            
💾 자동 저장

                            
작업 내용을 로컬에 자동 저장하며, 서버에 저장하여 언제든 불러올 수 있습니다.

                        

                        

                            
📤 DDL 내보내기

                            
작성한 ERD를 MySQL, PostgreSQL, Oracle SQL DDL 코드로 변환합니다.

                        

                    

                


                

                    
🎨 아이콘 설명

                    
    
                        
  • 🔑 PK: Primary Key (기본키) - 테이블의 고유 식별자
    • 
                        
  • 🔗 FK: Foreign Key (외래키) - 다른 테이블을 참조하는 키
    • 
                        
  • NN: Not Null - NULL 값을 허용하지 않음
    • 
                    

                


                

                    
💡 팁

                    
    
                        
  • 테이블을 우클릭하면 편집/삭제 메뉴가 나타납니다
    • 
                        
  • 관계선을 클릭하면 관계 설정을 편집할 수 있습니다
    • 
                        
  • 모든 변경사항은 자동으로 저장됩니다 (저장 버튼 불필요)
    • 
                        
  • 여러 사용자가 동시에 작업할 경우 버전 충돌이 발생하면 병합 옵션이 제공됩니다
    • 
                    

                


                

                    
❓ 자주 묻는 질문

                    

                        Q: 테이블을 삭제하려면?
                        
A: 테이블을 우클릭하고 "삭제"를 선택하거나, 테이블 편집 모달에서 삭제할 수 있습니다.

                    

                    

                        Q: 여러 컬럼을 PK로 지정할 수 있나요?
                        
A: 네, 복합 기본키(Composite Primary Key)를 만들 수 있습니다.

                    

                    

                        Q: 저장한 다이어그램은 어디에 있나요?
                        
A: "📂 불러오기" 버튼을 클릭하면 저장된 다이어그램 목록을 볼 수 있습니다.
